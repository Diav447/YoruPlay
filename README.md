# YoruPlay

A native Android local audio and video player.

## Tech stack

- Kotlin
- Jetpack Compose
- Material 3
- AndroidX Media3 (planned)

## Requirements

- Android 8.0 or newer
- JDK 17 for the build environment

## Build

Debug APKs are built by GitHub Actions.

The initial project is a UI skeleton. Local media playback will be added
in subsequent development phases.
